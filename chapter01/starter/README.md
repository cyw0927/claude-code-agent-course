# Chapter 01 Starter

Chapter 01 실습에 사용하는 최소 Task Manager 코드입니다.

## 실행

Windows PowerShell:

```powershell
python app.py
```

macOS / Linux:

```bash
python3 app.py
```

예상 출력:

```text
=== Task Manager ===
1. Claude Code 학습하기
2. Agent 개념 정리하기
3. 실습 결과 기록하기
```

외부 패키지는 필요하지 않으며 Python 3만 있으면 실행할 수 있습니다.
