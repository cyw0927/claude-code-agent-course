# Chapter 02 Starter — Single Agent Task Manager

이 폴더는 Chapter 02 실습에서 사용하는 Starter 코드입니다.

## 실행 환경

- Python 3
- 외부 패키지 없음

## 실행

Windows PowerShell:

```powershell
python app.py list
```

macOS / Linux:

```bash
python3 app.py list
```

예상 결과:

```text
=== Task Manager ===
[ ] 1. Claude Code 학습하기
[ ] 2. Agent 개념 정리하기
[ ] 3. 실습 결과 기록하기
```

현재 이 Starter는 `list` 명령만 지원합니다.

강의에서 안내하는 실습에 따라 Claude Code로 기능을 확장해 사용하세요.
