# Chapter 04 Starter Resource

이 폴더는 Chapter 04 실습용 Starter 리소스입니다.

Python 3만 있으면 실행할 수 있으며 외부 패키지는 필요하지 않습니다.

## 실행

```bash
python app.py list
```

## 테스트

```bash
python -m unittest discover -s tests -v
```

이 Starter는 실습을 위해 일부 테스트가 실패하는 상태로 제공됩니다.

강의 또는 블로그의 안내에 따라 코드를 수정한 뒤 전체 테스트와 `git diff`를 확인하세요.
