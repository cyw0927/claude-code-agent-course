# Human Review Checklist

## 요구사항

- [ ] 요청한 기능이 구현되었다.
- [ ] 정상 입력이 의도대로 동작한다.
- [ ] 오류 입력이 안전하게 처리된다.
- [ ] 기존 기능이 유지된다.

## 테스트

- [ ] 전체 테스트를 실행했다.
- [ ] 실패 테스트가 0개다.
- [ ] 테스트를 삭제하거나 약화하지 않았다.
- [ ] 특정 입력만 통과하도록 하드코딩하지 않았다.

## 변경 범위

- [ ] `git diff`를 직접 확인했다.
- [ ] 필요한 파일만 변경되었다.
- [ ] 요구하지 않은 기능이 추가되지 않았다.
- [ ] 불필요한 리팩터링이 없다.

## 최종 판단

- [ ] PASS
- [ ] FIX_REQUIRED
